## 확인하지 못한 것과 참고

- 로그인 때 읽은 직원 이름과 역할은 세션에 남는다(비밀번호 해시는 인증 뒤 지운다). 로그인 뒤 이름이나 역할이 바뀌면 다시 로그인할 때까지 `me`와 권한에 이전 값이 남는다. 계정·역할을 바꾸는 기능은 없다(하지 않을 일).
- 주소 변형 `GET /API/employees`, `GET /api//employees`는 직원만 계정에서 2xx가 아님을 단언했다(각각 표에 없는 요청이라 403, 방화벽이 거부). 정확한 상태 값은 단언하지 않았다.
- `AuthApiTest`의 테스트 메서드 이름 4개는 레드 뒤 Checkstyle 때문에 바꿨다(위 기록). 단언은 그대로다.
- macOS에서는 실행하지 않았다.
- T#3 `ApplicationStartupTest`는 기본 경로 `backend/data/app.db`를 쓰므로 `make build`·`make test`가 로컬 데모 DB에 스키마와 시드를 넣는다(T#5 이후 동작, 이 태스크와 무관, T#4 증거에도 적었다).
