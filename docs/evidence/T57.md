## 바뀐 파일

- `backend/src/main/resources/application.yml`: `server.address: ${SERVER_ADDRESS:127.0.0.1}` 추가(B#15).

- `scripts/run.sh`(새 파일): Node 버전·포트 확인 후 백엔드·프런트엔드를 함께 띄우고 Ctrl-C로 함께 내림
  (피드백 8). `scripts/e2e-servers.sh`의 `port_in_use`·프로세스 그룹·트랩 패턴을 재사용.

  `DB_PATH`는 무시), 저장소 밖 경로 거부, 백엔드 실행 중이면 거부(B#5, 데이터 삭제).
- `Makefile`: `run`, `reset-db` 타깃 추가.
- `.gitignore`: `*.db-wal`·`*.db-shm`·`*.db-journal` 추가.
- `README.md`: "DB 준비"에 `make reset-db` 사용법, "실행"에 `make run`(권장)과 포트 변수, 기존 두 터미널
