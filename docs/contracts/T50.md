## 수용 기준

1. **다섯 commit의 변경 대조.** `docs/evidence/T50.md`의 `## 다섯 commit의 변경` 절에 ` ```changes ` 블록이 있고, 그 내용이 아래 명령의
   출력과 글자까지 같다.
   - 확인: `diff <(git show --name-status --format=%H 82973c38fcedd52c0383d67aa131906bd1cc2b41 1f3ca6f130cd34026b892293ad625132f9898430 0d8b66fe3dce3e285a452cac7c4adc6e5f463a8e a4f5c995792bca66a5520741e2ed6418a90b7a14 bb515a53783363af577ad5bd5a5da4787f2b88a2) <(awk '/^```changes$/{f=1;next} /^```$/{f=0} f' docs/evidence/T50.md)`의 종료 코드가 0.
   - 준비: 증거에 그 절과 빈 ` ```changes ` 블록만 둔다. 레드: 블록이 비어 `diff`가 차이를 내고 종료 코드 1.
2. **지금 `main`에 남은 것.** 같은 증거의 `## 지금 main에 남은 것` 절에 ` ```remains ` 블록이 있고, 다섯 commit이 더한(`A`) 파일마다
   `<commit 앞 8자> <경로> <gone|same|changed>` 한 줄이 아래 명령의 출력과 같다. `changed`인 파일은 표에서 그 뒤에 그 파일을 바꾼
   `main`의 commit(수용된 태스크 또는 요구사항 PR)을 적는다.
   - 확인: `diff <(for c in 82973c38 1f3ca6f1 0d8b66fe a4f5c995 bb515a53; do for f in $(git show --name-only --format= --diff-filter=A $c); do if git cat-file -e c2e545188c1b2f883a388a1ce1dfe79dfa8e8656:$f 2>/dev/null; then if [ "$(git rev-parse c2e545188c1b2f883a388a1ce1dfe79dfa8e8656:$f)" = "$(git rev-parse $c:$f)" ]; then s=same; else s=changed; fi; else s=gone; fi; echo "$c $f $s"; done; done) <(awk '/^```remains$/{f=1;next} /^```$/{f=0} f' docs/evidence/T50.md)`의 종료 코드가 0. 기준 commit은 검사를 한 `main` `c2e5451`로 고정한다.
   - 준비·레드: 기준 1과 같다(빈 ` ```remains ` 블록).
3. **앱 코드 없음, 키트 파일 그대로.** 다섯 commit이 `backend/`·`frontend/` 아래 파일을 하나도 바꾸지 않았고, 지금 `scripts/nexi-fingerprint.sh`와
   `scripts/nexi-isolated.sh`가 키트의 `nexi-init/assets/` 사본과 같다.
   - 확인: `git show --name-only --format= <다섯 commit> | grep -cE '^(backend|frontend)/'`가 `0`. `cmp scripts/nexi-fingerprint.sh <키트>/nexi-init/assets/nexi-fingerprint.sh`와
     `cmp scripts/nexi-isolated.sh <키트>/nexi-init/assets/nexi-isolated.sh`의 종료 코드가 0.
   - 이 기준은 `regression`이다: 기록의 사실이라 작업 전에도 성립한다. 증거에 작업 전(`c2e5451`) 실행 결과를 베이스라인으로 적는다.
4. **결정과 이슈의 대상.** 이 계약서의 `## 결정`이 다섯 commit 각각을 그대로 두는 까닭을 적고, 증거가 그 결정을 기준 1–3의 결과와 함께

     (`regression`: 이슈를 만들 때 넣었다). 결정 내용은 리뷰어가 기준 1–3의 블록과 대조한다.
5. **회귀.** `make build`, `make test`, `make lint`가 작업 전(`t50` = `origin/main` `c2e5451`)과 작업 뒤에 통과한다. 이 태스크가
