# 답변

`QUESTIONS.md`의 질문에 대한 답이다. 고객 답변이 아니라 수행 팀(PM)의 답이다.

근거:

- `원문`: `REQUEST.md`가 답한다.
- `수행사 결정`: 수행 팀이 정했다. 괄호 안은 출처다.
  - `legacy §x`: NEXI 이전 팀 결정 `docs/legacy/REQ-CONTEXT.md` "1. Core Decisions"
  - `legacy foundation`: `docs/legacy/foundation.md`
  - `PM 답`: 이번 answers 단계에서 PM이 직접 답했다.
  - `제안 수용`: Claude가 제안했고 PM이 "나머지는 제안대로"로 받아들였다.
